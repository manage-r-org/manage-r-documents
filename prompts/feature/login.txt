# 3. Request

Use the project's existing DTO and validation conventions.

Preferred request:

```json
{
  "identifier": "tasin@example.com",
  "password": "StrongPasswordHere"
}
```

The `identifier` should follow whatever login strategy the existing authentication design supports.

If the current design supports email only, use email.

If the existing design intentionally supports username/email, preserve that behavior.

Do **not** invent additional login methods.

Never accept:

```text
userId
role
passwordHash
```

from the client.

---

# 4. Authentication lookup

The service should:

1. Locate the user using the supported identifier.
2. Ensure the account exists.
3. Verify the supplied password against the stored password hash.
4. Reject invalid credentials using the project's existing authentication/exception conventions.

Do not reveal whether the username/email exists.

For example, avoid responses such as:

```text
User does not exist
```

when the password is incorrect.

Prefer one generic authentication failure such as:

```text
Invalid credentials
```

This prevents unnecessary account enumeration.

---

# 5. Password verification

Reuse the project's existing password/hash utility.

Conceptually:

```text
plain password from request
          ↓
compare with stored password_hash
          ↓
match?
 ┌────────┴────────┐
YES                NO
 ↓                  ↓
continue       reject login
```

Never:

* decrypt the password
* compare plain-text passwords
* log the password
* return the password hash

# 11. Security requirements

Ensure:

* passwords are never logged
* password hashes are never returned
* invalid credentials use a generic error
* JWT secrets come from environment/configuration
* JWT expiration comes from configuration
* sensitive information is not placed inside JWT claims
* client cannot choose its own role
* database errors are not exposed directly
* existing rate limiting/throttling remains active
* existing security middleware remains untouched

Do not weaken any existing security configuration to make login work.
