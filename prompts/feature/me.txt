# 2. Endpoint

Implement:

```http
GET /api/v1/auth/me
```

This endpoint returns information about the **currently authenticated user**.

The client should send:

```http
Authorization: Bearer <access-token>
```

There must be no:

```text
userId
email
username
```

parameter that allows the client to choose which user to retrieve.

The authenticated JWT determines the user.

# 11. Authorization vs authentication

`/auth/me` is an **authentication** endpoint, not an admin endpoint.

Both:

```text
admin
user
```

should be able to call it when authenticated.

Do not add:

```text
RolesGuard
@Roles('admin')
```

unless the existing requirements specifically demand it.

The endpoint answers:

> "Who am I?"

not:

> "Which users am I allowed to manage?"
