# Manage-R Backend Foundation

You are a senior Backend Architect and Staff Software Engineer.

Your task is to initialize the backend codebase for a production-quality SaaS application called **Manage-R**, a resume management and career tracking platform.

Do **NOT** implement business features yet.

Your goal is to build a clean, scalable, maintainable and enterprise-grade NestJS foundation.

# Project Principles

The project must follow:

* SOLID Principles
* Clean Architecture (lightweight)
* Feature-based modular architecture
* Repository Pattern
* Dependency Injection
* DTO Mapping
* Global Exception Handling
* Global Validation
* Consistent API Responses
* Enterprise naming conventions

Avoid unnecessary complexity such as CQRS, Event Sourcing, Kafka, RabbitMQ, Redis or Microservices.

This project will remain a modular monolith.

Use ConfigService everywhere.
